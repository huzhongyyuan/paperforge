# 图表与审美：让视觉结构承担论证

本页依据 [15 个实际查看的局部图例](paper-cards.md)提炼设计选择，并记录原图的可读性问题。自动 caption 分类、像素密度和颜色统计只用于筛选，不能证明“美观”或被录用的原因。以下建议跨主题可迁移；具体会议版心、字体与页限另查当前官方要求。

## 先选择图的任务

| 读者需要知道什么 | 适合的视觉结构 | 先准备的真实输入 |
|---|---|---|
| 任务是什么、现有方案错在哪 | 少量对齐的输入/基线/目标或输出，突出一个可辨认失败 | 相同样本、时间点、条件；基线身份；裁剪位置 |
| 新方法如何工作 | 输入→共享计算→新机制→输出；局部机制用 inset | 实际计算依赖、训练/推理差异、关键张量 |
| 为什么这一步有效 | 配对干预、机制示意与直接观测并排 | 受控对照、测量定义，不用注意力图代替因果 |
| 结果在哪些条件成立 | 分层结果、相同轴的曲线、小倍图 | 全部相关条件与真实数值、成本轴 |
| 数据增加了什么 | 多模态对应样例＋覆盖统计 | 单位、类别/因素、计数分母、质量依据 |
| 时间一致性如何 | 相同帧序列＋定义清楚的时空切片/误差图 | 帧索引、切片位置、时间轴及对齐规则 |

## F1：框架图先显示路径，再解释算子

**触发/操作**：模块多且箭头交叉时，按计算依赖排列；共享主干画一次，分支在实际分叉处展开，训练专用支路加线型/文字。只有新意相关的算子进入放大图。

**来源**：[FreeU](paper-cards.md#f800a97293edd4ff6088e891) p.2 总览→局部操作；[VideoGigaGAN](paper-cards.md#71ca4dbb84e8c875682c2ccf) p.4 全局架构＋局部 inset；[EffectErase](paper-cards.md#b28e3c265e414c05ffd2213c) p.5 共享 DiT 与两任务颜色。**边界**：EffectErase 原图较密，学习其共享结构而非复制所有小字。**验收**：沿箭头可口述一次推理；图、公式、训练状态一致；缩到最终列宽仍能读关键标签。

## F2：颜色表达类别或数值，不做装饰

**触发/操作**：同类对象跨图统一色义；类别同时配标签/线型，数值用有说明的连续或发散色标。共享零点/量纲的矩阵使用共同色标；多类别太拥挤时拆成小倍图或排序条形图。

**来源**：[Task Transfer](paper-cards.md#fecf4b9fa84210facabbf931) p.2 三张对齐矩阵；[OLATverse](paper-cards.md#2a6d999de916b800b3bea578) p.4 多类别分布图；EffectErase 两任务配色。**边界/反例**：Task Transfer 红绿编码有无障碍风险，OLATverse 多色与小标签增加阅读负担。推荐替代是本模块设计判断，不是原论文结论。**验收**：灰度/色觉模拟中能解码类别；色标可比较，不通过每图重缩放夸大差异。

## F3：定性对比固定坐标，不靠挑选裁剪制造优势

**触发/操作**：以样本为行、方法/条件为列或相反，但一张图保持一致；输入、目标、输出使用同一 crop 和时刻；框颜色只指位置，放大倍率明确。选例用于展示现象，另给定量覆盖范围。

**来源**：[EffectErase](paper-cards.md#b28e3c265e414c05ffd2213c) p.2 动机、p.7 Fig.7；[Video Depth Anything](paper-cards.md#b4fa856bef2cee9204ad8cc5) p.7 Fig.6。**边界**：当前预览只覆盖各页上部；不据此评价整页布局。**验收**：各方法能对应同一内容；相同图像处理；代表性失败没有被当成普遍失败率。

## F4：动态结论需要动态证据

**触发/操作**：若主张时间稳定，静态高清帧之外加相同帧序列、定义好的时空切片或相关误差。先在小示意中解释切片取自哪里，再展示跨方法对照。

**来源**：[VideoGigaGAN](paper-cards.md#71ca4dbb84e8c875682c2ccf) p.5 Fig.4：y–t 切片及逐步变体。**边界**：切片只检查所取位置，不覆盖整段所有对象；累加变体也不是独立效应。**验收**：读者知道空间轴、时间轴和采样位置；可在原视频定位。

## F5：曲线与热图保留比较条件

**触发/操作**：预算不同则用质量—成本曲线或明确的同预算切片；多个条件用共同坐标小倍图。点数少不靠连线或拟合外观制造确定性。误差条、重复次数只用真实记录。

**来源**：[Dataset Distillation](paper-cards.md#f981f123b2ada842bea1db44) p.2 标签机制分面和计算预算；[VBench](paper-cards.md#7408bccff4dcfda8985400df) p.7 多维度人评/自动分数。**边界**：VBench 每小图模型点少；视觉相关不等于逐样本可靠。**验收**：横纵轴、归一化、比较组能独立读懂；正文结论遵守点和曲线覆盖范围。

## F6：表格以比较问题组织

**触发/操作**：组标题表示真实协议差异，列按观测对象归类；避免第一列重复长段，可用短标签加一次释义。指标方向放表头，单位/缩放一次说明；真实可比组内加粗最佳、次佳按用户要求加下划线，必要时处理并列。

**来源**：[EffectErase](paper-cards.md#b28e3c265e414c05ffd2213c) p.7 Table 2 区分 with/without GT；[PTv3](paper-cards.md#a175f954c059c77aad6dc20d) p.3 效率表与瓶颈图互补。**边界**：不可比行分组而非统一排名；删行应因问题范围，不能只为确保 ours 获胜。**验收**：看 caption 即知行身份、指标意义、最佳方向；缩放后数值可读，不靠强制压扁解决溢出。

## Caption：图中的证据和读图说明

写明对象/问题，再解释 panel、符号、关键条件，最后给图能支持的观察。Caption 的信息与正文互补：正文解释为什么，图注解释看什么和如何读。完整网络推导不塞图注，决定比较的协议不全移正文。未实际看到完整 caption 时，不声称已核对它。

## 篇幅与版面让空间服务论证

**触发**：页限紧、图文分离、大块空白、caption 孤行或表格在节标题之前。

**操作顺序**：

1. 先确定该页要完成的论证：动机、机制或证据。主文保留理解/评价结论必需的信息；附录承接可复现细节与完整结果。
2. 删除跨章节重复的模块清单、背景和指标复读；保留协议身份与负结果。长公式只在推导必要时保留正文。
3. 检查 figure/table 浮动、不可分页 minipage 和强制断页；小图按可读性选择单栏，大图按信息结构选择跨栏。不能仅为了填满空白扩大图片。
4. Caption 的孤行优先用准确精简或必要解释解决；不要添加没有含义的形容词。不要通过越界字号、边距或大量负间距绕过会议要求。
5. 编译检查修改页及其后续页面：首次引用顺序、节标题、caption、图表标签、裁剪和总页数。最终 PDF 的页面才是排版证据。

**来源/边界**：这是以上图例与统一 layout 工作流导出的设计建议；自动页数含参考文献/可能附录，不能推导主文页配额。CVPR 双栏图例不规定 ICLR 的图宽或摘要位置。Ego-Exo4D 大作者块也不适合作为匿名稿首页模板。

**可观察验收**：最终尺寸关键文字可读；一眼能辨任务、比较组和新机制；视觉编码不改变数据含义；图源可编辑，数值图保留生成代码和真实输入。美观可讨论，证据正确性须逐项核对。
