# 科学数据图与多面板结果图

配合 [统一图表流程](integrated-figures.md) 使用，适用于 CCF-A 实验图及期刊数据图。输入为真实日志、表格、数据和已说明的分析；输出为可复现绘图代码、图文件与 caption。

## 画之前核对数据含义

确定横纵变量、单位、独立样本／重复测量关系、汇总方式、缺失与排除，以及误差线代表 SD、SE、CI、分位数还是其他量。记录数据来源、过滤、归一化、平滑、分箱与统计计算。现有记录已有这些内容时直接引用。

| 读者要比较什么 | 合适的表达与检查 |
|---|---|
| 方法或配置差异 | 点图、区间或分布；有配对关系时保持配对，不把均值当成全部分布 |
| 质量—效率取舍 | 对齐硬件、数据和协议，区分延迟、吞吐、峰值显存与总成本 |
| 时间／训练变化 | 真实采样位置和重复实验，缺失保留断点；平滑不掩盖尖峰与失败 |
| 多面板强度／差值 | 同一比较使用一致的单位和归一化；不同尺度显式说明 |
| 个体轨迹与总体估计 | 标明个体 ID 和独立单位；不把同一对象的多行测量当作独立样本计算 CI |

## 编码和布局

柱长或面积通常从零基线解释；点线图可采用有意义的非零范围，但需显示刻度和上下文。对数坐标说明变换及零／负值处理。颜色按类别、顺序或正负差异选择，并辅以线型、标记或直接标签；共用 colorbar 时必须共用实际映射。

区分零、缺失、删失与排除。不要为了连续曲线隐式连接缺失观测，也不要靠双轴范围制造相关关系。统计单位不明时先厘清，不能默认“表格每行都是一个独立样本”。

使用 Matplotlib/Seaborn 等从实际数据绘制，先设最终物理尺寸，再检查字体、图例和面板间距。用局部 style context 避免修改全局绘图配置；精确物理尺寸导出时注意紧裁剪可能改变最终页面大小。

## 导出和验收

保留数据、代码、分析说明及可编辑源，按用途导出 PDF/SVG 与 PNG 预览。SVG 保留文字依赖字体可用性，转轮廓保留外观但失去文本编辑；PDF/SVG 内仍可能含栅格内容，不单凭后缀声称全矢量。

检查最终尺寸、字形、裁切、线条、误差范围、坐标、图例和 caption 是否一致。caption 给出样本量、独立单位、误差线定义和必要协议；没有算过显著性或区间就不补写。具体期刊的分辨率、尺寸、文件格式与字体要求使用当前官方来源，模板配色不等于出版合规。
