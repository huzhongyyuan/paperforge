# 可选组件与布局

本页将分享包的视觉语汇接到统一图表路线。这些是适用于部分 CV／视频框架图的组件，不是作者统一标准或论文必须使用的皮肤。原包统计的出处和局限见 [source evidence](source-evidence.md)。

| 表达对象 | figkit 组件 | 使用时核对 |
|---|---|---|
| 编码／解码 | `trapezoid()` | 收缩方向与真实表示变换一致 |
| 视频与潜变量 | `stack()`、`slab()`、`noise()` | 帧顺序、时间语义；噪声不能冒充实测分布 |
| 通用模块 | `block()`、`container()` | 模块登记名称、继承／新增、实际接口 |
| 网络层示意 | `bar()`、`unet()` | `unet()` 只是示意组件；真实骨干非 UNet 时改拓扑 |
| 参数状态 | `fire()`、`snow()`／`state` | 图例定义；逐阶段更新状态，新增不等于可训练 |
| 随机采样／外部模型 | `dice()`、`robot()` | 只有实际涉及该操作时使用 |
| 合并与条件 | `op()`、`rich()` | 加法、乘法、拼接等算子含义不能混用 |
| 主路径／监督／反馈 | `arrow()`、`curve()` | 线型／颜色含义、训练或推理归属和更新时钟 |
| 局部放大 | `zoom()` | 与总图对应同一计算，放大线不当作数据流 |
| 数学标签 | `math()` | 来自方法公式；使用 Matplotlib mathtext 绘成路径 |

默认 spatial／cross／temporal 使用不同配色，可按研究重定义，但须同步图例与各 panel。不要把 `temporal` 固定等同“新模块”，也不把 lime、手写字体或火焰图标当作案例构图的必要条件。字体 Comic Neue 是替代字体，原包并未据此核实原作者字体。

组件返回 `Box`（`unet` 返回 box 和列），连线用 `.left/.right/.top/.bottom/.at(side,t)`，减少重复手算坐标。背景容器先画，再画内容与连接；避免边线穿字，短标签解释由 caption 承接。使用 `schematic(part, why)` 声明概念曲线或占位素材。

按真实依赖选布局：

- **训练在上、推理在下**：共享骨干而输入／分支不同；对齐同一组件并标更新状态。
- **主路径与细节列**：总图定位关键机制，旁栏展开操作或损失；分隔线不代表计算边。
- **阶段纵向堆叠**：实际存在有序训练阶段时用，对齐骨干让状态变化可读。
- **主路径与下方放大**：少数局部操作需要展开时使用，保留跨分区对应。
- **单行路径**：方法短、依赖简单或版面紧凑时使用。

不强制原包约 2.25 的宽高比、固定图像占比或模块数量。输入输出图像只在有解释价值时加入；不能靠加大无关图片满足视觉统计。现有作者案例与字体／导出证据仍以 `modules/case-library/references/figure-playbook.md` 为准。
