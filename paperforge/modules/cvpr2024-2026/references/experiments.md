# 实验论证：让每张表回答一个问题

使用链条：**主张 → 可检验问题 → 比较对象 → 协议 → 指标 → 观察 → 适用范围**。它是检查工具，不要求七个小标题或固定三节。先读取用户已有结果和协议，不因写作需要擅自追加训练。

## E1：比较的对象必须可以辨认

**触发/诊断**：主表和消融都叫 Full，模型规模、训练预算或数据却不同；读者可能把两行当作同一个模型。

**操作**：为表中行建立最小身份：模型/权重版本、训练数据与预算、推理条件、评测集合和统计单位。只把决定比较含义的差异写在 caption 或 setup；路径和执行日志进入复现材料。局部消融的参考行可用明确的变体名。

**来源**：[Video Depth Anything](paper-cards.md#b4fa856bef2cee9204ad8cc5) p.7：消融用 VDA-S、window 16，默认不含 image distillation；与主模型身份分开。**边界**：未完成的同条件比较不能靠改名补齐。**验收**：读者仅看表和相邻协议就能判断哪些行可直接相减。

## E2：不同消融回答不同问题

| 比较设计 | 能回答 | 不能直接推出 |
|---|---|---|
| 相同训练条件下单组件移除 | 在该训练/评测设置中，该组件的条件贡献 | 所有设置下的必要性、与其他组件无交互 |
| 固定权重关闭输入/分支 | 当前模型对该条件的敏感性或依赖 | 没有该组件重新学习后的最佳能力 |
| A→A+B→A+B+C 累加 | 沿该顺序的增量 | B、C 各自独立效应或所有交互 |
| 同算力或同质量比较 | 指定预算/质量下的效率 | 在任意预算下都最优 |

**触发/操作**：若叙述混用了这些含义，先核实真实操作，再缩小归因或补真正需要的对照计划；写作本身不授权运行。正文可以简洁，但须在读者可找到的协议处保留这些区别。

**来源**：[EffectErase](paper-cards.md#b28e3c265e414c05ffd2213c) p.7 Table 3 是 Real→EC→TARG→Syn 的累加；[Dataset Distillation](paper-cards.md#f981f123b2ada842bea1db44) p.8 要求同算力和相同学习率时程。**验收**：解释与实际干预一致；长时程提前停的 checkpoint 没被冒充为短预算独立训练。

## E3：指标有效性先于排名

**触发/诊断**：用一个综合分数支撑多个能力，或将分布/感知代理分数当作特定现象的直接测量。

**操作**：标出指标观测对象、方向、单位、聚合方式和失效条件；新指标用人工判断、已知扰动或可靠参照检查有效性。与模型排名分开陈述。学习型特征空间和归一化定义变化时，先检查可比性。

**来源**：[VBench](paper-cards.md#7408bccff4dcfda8985400df) pp.5–6：维度导向人评和自动分数的对应；[GigaHands](paper-cards.md#9e532d6a1fb5f3d41756fcd2) p.6：不同数据集分别训练特征提取器；EffectErase p.7 的 FVD 表述不宜直接作为“时序平滑已证明”的模板。**边界**：少数模型上的聚合相关性不等于逐视频测量有效；经验参照最高分不等于理论上界。**验收**：每个能力主张至少有能观察该能力的证据；相邻帧、跨间隔 AUC 等口径不混填。

## E4：分析写变化及含义，同时保留相关反向结果

**触发/诊断**：逐列复述数字、只选赢的列，或把折中写为全面提升。

**操作**：先回答该表的问题，选最能支撑判断的变化，用一两项相关代价界定结论。原始值保留足够精度，正文做合理四舍五入；绝对差和相对变化写清。只在可比的组内按真实方向标最佳/次佳，平局规则一致，`—` 不参与排名。

**来源**：[SenCache](paper-cards.md#6462ee844611f804b8e9e9f0) p.8：计算量平台与质量下降可共存；[Dataset Distillation](paper-cards.md#f981f123b2ada842bea1db44) p.8 Table 3 有不支持全面领先的条目。**边界**：单次结果或无误差条不能自动写“显著”；精确差值不等于可靠因果。**验收**：先搜索表中反例，再检查结论是否仍成立；选列的理由是研究问题，非名次。

## E5：数据贡献分开验证覆盖、质量和用途

**触发/诊断**：用数据规模代替标注准确性，用几个展示样本代替覆盖统计。

**操作**：分别报告采集/样本单位、关键因素覆盖、监督质量及下游可用性；说明质量检查的抽样范围和残余误差。评测子集的单位与训练总体分开，划分条件必须能支持相应泛化主张。

**来源**：[OLATverse](paper-cards.md#2a6d999de916b800b3bea578) pp.5、8：光照控制与重建法线/反照率精度不同；[GigaHands](paper-cards.md#9e532d6a1fb5f3d41756fcd2) pp.5–6：序列、剪辑和 motion-text 对不同；[Ego-Exo4D](paper-cards.md#41ca9fbe640d4a45cca1a3e2) pp.1–3：模态对应不同问题。**验收**：“audited”有具体审核对象，“ground truth”有测量依据，“unseen”有与其匹配的划分定义。

## E6：效率主张要同时暴露质量和成本轴

**触发/诊断**：只报加速倍数或 FLOPs，比较精度、硬件、分辨率、后处理不清。

**操作**：先定位瓶颈，再分别测核心计算与端到端成本；在同质量/同预算或曲线上比较。记录影响时延的硬件、precision、batch、输入大小和计时范围，保留真实的质量折中。

**来源**：[PTv3](paper-cards.md#a175f954c059c77aad6dc20d) pp.1–3 的 KNN/RPE 成本；[Video Depth Anything](paper-cards.md#b4fa856bef2cee9204ad8cc5) p.7 的 A100/518×518/各行 precision；[SenCache](paper-cards.md#6462ee844611f804b8e9e9f0) pp.5、8 的阈值和缓存策略。**验收**：参数量、FLOPs、latency不互相替代；“更快”能指向确定条件下的比较。

## 从结果表到正文

先写一句回答研究问题的结论，再写决定性的变化、解释及必要范围。若多个结果彼此矛盾，分开说明它们观测的对象；不能用总分掩盖。主文保留结论所依赖的对照，补充材料放完整因素、失败、协议和扩展结果。不要为显得整洁删除关键身份，也不要把训练日志逐行搬进论文。
