# CVPR 2024–2026：蒸馏什么，如何复用

目标是帮助写作者在自己的研究条件下作出更好的决定。全会论文用于建立覆盖与分布，重点论文用于解释可迁移的论证动作；句式、段数、色板不能脱离研究条件成为模板。

## 七层能力

| 层 | 观察对象 | 要提炼的决策 | 实际输出 / 验收 |
|---|---|---|---|
| 贡献类型 | 方法、数据/benchmark、效率系统、理论/分析、实证发现；可以混合 | 论文到底新增什么可被检验的知识？相应最低证据是什么？ | 一句话主张、最接近工作、能区分二者的证据；不能用模块数量代替贡献。 |
| 全文论证 | 任务 → 可行已有方案 → 具体局限 → 机制或需求 → 方案 → 证据 | 何时按问题组织，何时按观察、能力或系统瓶颈组织？ | 论证图；每条关键箭头能由事实、推导或实验解释，非仅靠连接词。 |
| 章节职责 | title / abstract / intro / contributions / related work / method / experiments / conclusion / limitations / appendix / captions | 该章节需要让读者知道什么，哪些信息应延后，哪些不可省？ | 可直接使用的改写；跨章节术语、承诺和证据一致。段数依内容与版式决定。 |
| 句段衔接 | 已知信息 → 新信息、指代、因果动词、并列层级、术语首次定义、过度名词化 | 读者究竟在哪一步需要自行补逻辑？ | 标出断点，补充真实关系或调整顺序；不靠堆 however / therefore 修补。保留必要条件。 |
| 实验论证 | claim → question → comparison → protocol → metric → finding → scope | 如何证明为什么有效、在哪有效、代价与失败是什么？ | 主张—证据映射；对比和消融各自回答问题，避免指标流水账和选择性排名。 |
| 图表表达 | teaser、motivation、framework、机制图、定性/定量、数据图、caption | 哪种视觉编码最能缩短理解路径？ | 内容蓝图、信息层级、可编辑图源、匹配真实证据；按最终尺寸检查小字、对应关系和结论。 |
| 篇幅与呈现 | 读者负担、图文分工、主文/附录、表头、页内顺序、局部密度 | 哪里值得占篇幅，哪里可以压缩而不损失论证？ | 删除重复而非必要协议；表图靠近首次论证，caption不重复方法正文，遵守目标会议当前规范。 |

## 一条可复用规则的最低结构

1. **触发情境**：用户遇到的具体写作问题或研究类型。
2. **诊断**：为什么当前安排增加理解负担或缺少证据。
3. **写作操作**：移动、合并、补桥接、定义、比较或可视化什么；有多种合理选择时提供选择条件。
4. **来源**：论文、年份、presentation 标签、章节/页/图号；区分机器特征与实际定向阅读。
5. **适用边界和反例**：什么时候该换另一种组织；不能从单篇上升为全会惯例。
6. **验收**：一个可观察的检查，不用“像顶会”“更高级”充当标准。

示例形式：若方法的新意在两个阶段之间的信息依赖，framework应先显示阶段边界与传递对象，再放局部算子；若新意仅是单个算子的数学性质，则用机制图和相应性质检查更合适。此例是待案例支持的设计启发，不冒充已有统计结论。

## 证据分层与采样

- **官方目录**：CVF 三年主会 proceedings，排除 workshops；独立匹配官方 Oral / Highlight 标签。保存来源、抓取时间、hash、未匹配项与标题更名证据。
- **机器提取**：章节与图注检测、篇幅、语言计数、视觉代理特征。复用已有成功结果并保留来源与分析器版本；抽取失败独立报告。不把检测到章节当成已理解论证，不把像素统计当作审美评分。
- **定向研读**：按贡献类型、主题、年份和 presentation 分层，研究各段的论证动作及跨章节闭环。记录读了哪些页/章节，不默认“下载过 = 全文精读”。
- **实际看图**：查看代表图的图形、标签、对应关系、caption和正文引用，记录页/图号；只有这层才能支持具体视觉判断。
- **复用验证**：用未参与归纳的材料检查路由和操作是否合理；没有独立行为测试时明确仅完成结构/功能检查。

## 权重与外推

默认 Oral 3、Highlight 2、Poster 1；同一篇不叠加 Oral 与 Highlight 权重。未知标签保留在未加权分布，排除出加权分布，不猜成 poster。统计导出器显式覆盖早期元数据 manifest 的 unknown=1 兜底值，原始 manifest 保留用于追溯。权重用于优先研读及描述性聚合，不表示论文质量为三倍或该写法导致录用。

同时保留三类视图：未加权分布、3/2/1 加权分布、按年份和 presentation 分层的分布。跨年汇总应说明按论文加权还是三年等权；先按贡献类型解释再谈频率。一个启发若在某一类研究成立，应保留这个范围，不强求跨类型多数票。接受论文存在幸存者偏差，不能据此推导评分/录用因果。

## 交付结构与使用方式

维护入口仍是 `paperforge/SKILL.md`。本模块提供可查询语料、章节规则、语言操作、图表案例和覆盖说明，按任务加载，避免每次读入数千篇特征。

- **改一句/一段**：定位断点 → 读取对应章节与语言操作 → 直接改写 → 检查科学含义。
- **写一节/整篇**：识别贡献类型 → 主张—证据链 → 章节分工 → 匹配案例 → 起草与一致性检查。
- **画一图/改排版**：确定读者问题与真实素材 → 选择视觉结构 → 生成可编辑稿 → 最终尺寸检视。
- **查询顶会惯例**：运行语料查询；回答带分母、年份、标签、提取覆盖及局限，不能凭skill文本编造统计。

未来迁移到ICLR/ICCV或新主题时，复用决策结构与检查，重新核对会议规范和相关实例；不把CVPR双栏篇幅、具体配色或某作者固定段数复制过去。
