Video motion transfer aims to apply the motion of a reference video to new content described by a text prompt, which supports flexible video creation. The main challenge of this task is to preserve fine-grained motion and long-range structure at the same time. However, training-free guidance relies on the motion prior of the pretrained model and cannot recover motion outside that prior, while per-video tuning updates all features uniformly and therefore spends its capacity on bands that carry little motion. This coupling arises because existing methods treat motion features as a single signal, even though fine motion and global structure occupy different frequency bands. To address these challenges, we propose TideMotion, a frequency-aware framework that separates motion features by band and adapts each band independently. Specifically, we first design a Frequency-routed Motion Prior, in which a lightweight router assigns each band to a dedicated expert. Then, we introduce Band-wise Test-time Adaptation, which tunes only the experts relevant to the given reference video and leaves the rest of the backbone frozen. Moreover, we propose a Spectral Alignment Loss that constrains the generated motion to follow the reference in each band rather than in pixel space.
